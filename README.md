# 出退勤システム

個人の勤務記録を登録・管理し、勤務内容に応じた給与や交通費を確認するためのWebアプリケーションです。  
HTML・CSS・JavaScriptで画面を構成し、Firebase AuthenticationによるGoogleログインとCloud Firestoreによるデータ保存に対応しています。

## 主な機能

- Googleアカウントによるログイン
- 日付、勤務コマ、事務作業時間、特別給、備考の登録・編集・削除
- ヘルプ勤務先の登録
- ヘルプ勤務時・特別な通勤時の交通費入力
- 勤務記録の一覧表示
- 月別・年別の給与確認
- 給与単価の登録・変更・履歴管理
- ダッシュボードでの勤務状況・給与グラフの表示
- Firebaseを利用したデータ保存と端末間での共有

## 各ファイルの概要

### 画面を構成するHTML

| ファイル | 内容 |
|---|---|
| `index.html` | ログイン後に表示するホーム画面。勤務状況や給与グラフなどの表示領域を定義します。 |
| `input.html` | 勤務日、勤務コマ、事務作業時間、特別給、ヘルプ勤務、交通費などの入力画面です。 |
| `list.html` | 登録済みの勤務記録を一覧・カレンダー形式で表示する画面です。 |
| `edit.html` | 登録済みの勤務記録を編集・削除する画面です。 |
| `salary.html` | 月別・年別の給与や交通費の集計を確認する画面です。 |
| `rates.html` | コマ給や事務時給など、給与計算に使用する単価を設定する画面です。 |

### JavaScript

| ファイル | 内容 |
|---|---|
| `index.js` | 勤務データ・給与単価を取得し、ホーム画面の勤務状況や給与グラフを表示します。 |
| `input.js` | 入力内容の確認、新しい勤務記録の作成、Firestoreへの保存を行います。 |
| `transportation.js` | 交通費の金額入力欄を生成し、入力値の検証・取得を行います。経路検索は行わず、金額を直接入力する方式です。 |
| `list.js` | 勤務記録の取得、年月による絞り込み、一覧・カレンダーの描画、編集画面への移動を行います。 |
| `edit.js` | 保存済みの勤務記録をフォームに反映し、内容の更新や削除を行います。 |
| `salary.js` | 勤務記録と給与単価をもとに、月別・年別の給与および交通費を集計して表示します。 |
| `rates.js` | 給与単価の履歴を取得し、新規登録・編集・削除を行います。 |
| `firebase.js` | Firebaseの初期化、Google認証、Firestoreへのデータ保存・取得・更新・削除、給与計算、共通画面処理を担当します。 |
| `mobile-menu.js` | スマートフォン表示時のメニューの開閉を制御します。 |

### その他

| ファイル | 内容 |
|---|---|
| `style.css` | サイドバー、各画面のレイアウト、フォーム、表、カレンダー、スマートフォン表示などのスタイルを定義します。 |
| `firestore.rules` | Firestoreに対する読み書きの許可条件を定義します。Firebase側へのルールの反映はFirebase Console等で行います。 |
| `meiko.ico` | ブラウザのタブなどに表示するアイコン画像です。 |

## データ保存・システム構成

- **画面・フロントエンド**：HTML / CSS / JavaScript
- **Webサイトの公開**：GitHub Pages
- **ログイン認証**：Firebase Authentication（Googleログイン）
- **データベース**：Cloud Firestore

勤務記録と給与単価は、ログインユーザーごとにFirestoreへ保存されます。主な保存先は次のとおりです。

```text
users/{ユーザーUID}/
├── attendance/  # 勤務記録
└── rates/       # 給与単価の履歴
```

## 交通費の入力

交通費は給与とは分けて管理します。

- **ヘルプ勤務の交通費**：ヘルプ勤務を有効にした場合に入力できます。
- **特別な交通費**：雨天時など、通常とは別に交通費が発生した場合に入力できます。
- 交通費は経路検索ではなく、実際にかかった金額を直接入力します。
- 勤務記録には `transportation.help.totalFare` および `transportation.special.totalFare` として保存されます。

## 給与単価と計算

給与計算に関する共通処理は `firebase.js` にあります。給与単価は `rates.html`・`rates.js` から登録し、適用開始日をもとに勤務日に対応する単価を使用します。給与の集計・画面表示は `salary.js`、ホーム画面の給与グラフは `index.js` が担当します。

## 開発・公開

1. リポジトリをローカル環境に取得します。
2. HTML・CSS・JavaScriptを編集します。
3. Firebaseプロジェクトの設定が `firebase.js` に正しく記述されていることを確認します。
4. Firebase AuthenticationでGoogleログインを有効にし、利用するWebサイトのドメインを承認済みドメインに登録します。
5. Firestoreを作成し、適切なセキュリティルールを設定します。
6. GitHubリポジトリへ変更を反映し、GitHub Pagesから公開します。

画面の表示内容を変更する場合はHTML、画面の動作やデータ処理を変更する場合は対応するJavaScript、色・余白・文字サイズなどを変更する場合は `style.css` を編集します。Firebaseとの接続やデータ構造、給与計算の共通処理を変更する場合は `firebase.js` も確認してください。
